# Design Document — Milestone M5: ModelRouter + IntentParser

## 1. Objetivo
Implementar a inteligência de roteamento da Nullain. O `IntentParser` analisa a tarefa e classifica a intenção e complexidade (`LOW`, `MEDIUM`, `HIGH`). O `ModelRouter` mapeia a tarefa para o tier de modelo adequado (`fast`, `balanced`, `deep`), lê as configurações declarativas do `nullain.toml`, gerencia a cadeia de fallback com circuit breaker e valida a saúde dos modelos em runtime.

## 2. Configuração Declarativa (`nullain/config/settings.py`)
Modelos Pydantic-Settings lendo de `nullain.toml` ou variáveis de ambiente:
```toml
[router.tiers.fast]
models = ["gpt-oss:20b"]
max_context = 32000

[router.tiers.balanced]
models = ["qwen3-coder:480b-cloud", "gpt-oss:120b"]
max_context = 128000

[router.tiers.deep]
models = ["deepseek-v4-pro"]
max_context = 128000

[router]
fallback_chain = ["deep", "balanced", "fast"]
classifier_model = "fast"
```

## 3. Classificação de Intenção (`nullain/router/intent.py`)
- Heurísticas determinísticas primeiro: tamanho do diff, palavras-chave ("refactor", "architect", "commit", "format"), contagem de arquivos.
- Retorna `IntentResult`: `intent_type`, `complexity` (`LOW`, `MEDIUM`, `HIGH`), `suggested_tier`.

## 4. Roteamento com Circuit Breaker (`nullain/router/router.py`)
- `ModelRouter`: Escolhe o melhor modelo disponível para o tier requisitado.
- Circuit Breaker: Rastreia falhas consecutivas por modelo. Se 3 falhas ocorrerem, o circuito abre por N segundos e o roteador degrada para o próximo modelo da cadeia de fallback.
- Escalada automática de tier: Se a verificação de tarefas falhar 2x, a tarefa escala de `balanced` para `deep` automaticamente.
