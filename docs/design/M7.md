# Design Document — Milestone M7: Learning Loop + nullain-agentd

## 1. Objetivo
Implementar o Learning Loop v1 (memória episódica + estatísticas de roteamento em SQLite) e o daemon stdio NDJSON `nullain-agentd` para servir de ponte com o CLI em Go.

## 2. Learning Loop & Memória Episódica (`nullain/memory/`)
- `TrajectoryRecord`: Guarda intent, spec, modelo utilizado, quantidade de passos, resultado da verificação (`success`), feedback do usuário e fingerprint do repositório.
- `EpisodicMemory`: Indexa trajetórias no SQLite local (`~/.nullain/memory.db`). Ao iniciar tarefas similares, recupera 1–2 trajetórias de sucesso como exemplos few-shot no `PromptAssembler`.
- Estatísticas de Roteamento: Alimenta a taxa de sucesso por `(intent, model)` para informar o `ModelRouter`.

## 3. Protocolo NDJSON & `nullain-agentd` (`nullain/protocol/` & `nullain-agentd/`)
- Envelope v1: `{"v": 1, "type": str, "id": str, "payload": dict}`.
- Tipos de Mensagem: `session.start`, `user.message`, `agent.event`, `permission.request`, `permission.response`, `session.interrupt`, `session.end`.
- Schema Exporter (`nullain/protocol/exporter.py`): Exporta JSON Schema do protocolo para `schema/protocol_v1.json` para consumo direto pelo gerador de structs Go (`make schema`).
- `nullain-agentd`: Processo daemon síncrono/assíncrono que lê stdin linha por linha (NDJSON) e escreve deltas e eventos do agente no stdout (NDJSON).

## 4. Critério de Aceite
- Exportador de schema funcional (`make schema` gera `schema/protocol_v1.json`).
- Teste e2e em `tests/integration/test_agentd.py` com stdio NDJSON interagindo com `nullain-agentd`.
- Teste verificando que a memória episódica injeta poucos exemplos após execução bem-sucedida.
- `make check` 100% verde.
