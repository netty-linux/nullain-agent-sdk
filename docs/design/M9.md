# M9 — API pública e CLI

> Fase 2 do `PROMPT_FASES_CORRECAO.md`. Objetivo: tornar o SDK usável por quem
> não o escreveu. Hoje montar um agente exige instanciar `AgentLoop` +
> `ToolRegistry` + `Provider` + `PermissionPolicy` na mão; o `cli.py` tem 42
> linhas e não roda um agente; `__all__` exporta 106 símbolos.

## Decisões de design

**D1 — Fachada `Agent` (novo `nullain/agent/facade.py`).** Porta de entrada de
90% dos usuários. O construtor **monta** colaboradores com defaults seguros
(nunca reimplementa o loop): `OllamaCloudProvider` (de `settings.ollama_*`),
`ToolRegistry` + `register_default_tools`, `PermissionPolicy` fail-closed,
`ModelRouter` de `settings.router`, `select_sandbox(settings.sandbox)`. Métodos:
`async run(prompt) -> RunResult`, `async stream(prompt)` (async generator que
subscreve o `EventBus` e emite `BaseEvent` enquanto roda `run_result(streaming=True)`
em background, terminando com o `RunResult` final), e `run_sync(prompt)` (fachada
síncrona fina via `asyncio.run` — princípio 5 "async first, sync como fachada").
Construtores alternativos `Agent.from_settings(settings)` e `Agent.from_config(path)`.

**D2 — CLI com `argparse` estruturado (stdlib), não `typer`.** Justificativa
(regra 10): o CLI é um delegador fino para a fachada; `--json` é NDJSON via
`print`; o chat interativo reusa o `permission_callback` já existente ligado ao
TTY. Nenhuma dependência nova se justifica. Comandos: `run` (flags `--model`,
`--workspace`, `--max-steps`, `--json`), `chat` (multi-turno streaming + ASK no
TTY), `doctor` (provider alcançável, sandbox disponível, `nullain.toml` válido,
MCP inicializável, `rg` presente), `mcp list|add|remove`, `version`. Exit codes
por classe de falha; secrets nunca impressos.

**D3 — Enxugar `__all__` de 106 → ~25.** Manter: `Agent`, `AgentLoop`,
`RunResult`, `RunStatus`, `Conversation`, `EventBus`, `tool`, `ToolRegistry`,
`LLMProvider`, `OllamaCloudProvider`, `NullainSettings`, `load_settings`,
hierarquia de erros de topo (`NullainError` + subclasses observáveis), e os
eventos que o consumidor observa (`BaseEvent`, `ToolResultEvent`,
`UserMessageEvent`, `ErrorEvent`, `StreamDeltaEvent`). Tudo o mais continua
importável pelo caminho completo do módulo — redução de superfície declarada,
não remoção de código. Documentar em `docs/api-stability.md`.

**D4 — Docs e exemplos.** `docs/quickstart.md`, `configuration.md`, `tools.md`,
`architecture.md`; exemplos executáveis `01_basic_agent.py` … `05_mcp_server.py`;
README aponta para eles. Teste de smoke importa/executa os exemplos em dry-run.

## Definition of done

- `uv run nullain run "liste os arquivos python"` funciona ponta a ponta.
- Testes de CLI com provider fake (sem rede): exit codes + saída `--json`.
- Exemplos rodam (smoke test dry-run).
- `make check` verde.
- Commit: `feat(m9): Agent facade, real CLI, minimal public API, docs`.
