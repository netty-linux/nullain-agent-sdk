# M8 — Camada de edição de código (toolset de codificação)

> **Objetivo:** transformar o toolset de "agente genérico" em "agente de codificação".
> Arquivo-alvo: `nullain-tools/src/nullain_tools/filesystem.py` + `events/`.

## Decisões de design

1. **`FileAccessTracker`** (novo, em `nullain-tools/filesystem.py`): classe mutável
   com `mark_read(path)` / `was_read(path)`. Injetada em `create_filesystem_tools`
   via `file_access_tracker: FileAccessTracker | None = None`; quando `None`, cria
   uma instância fresca por chamada (backward-compatible). `read_file` marca o path
   resolvido; `edit_file`/`multi_edit` exigem `was_read` antes de editar. O daemon
   cria **um por sessão** no handler `session.start` e injeta.

2. **`read_file`**: novos `offset: int = 0`, `limit: int = 2000`. Saída em formato
   `cat -n` (`<linha>\t<conteúdo>`). Se o arquivo exceder `offset+limit`, rodapé
   explícito `... (N linhas restantes; use read_file offset=X para continuar)`.
   Linhas individuais > 2000 chars truncadas com `... [truncado N chars]`.
   Mantém `read_only=True`, `requires={READ}`.

3. **`edit_file`**: novo `replace_all: bool = False`. Conta ocorrências de
   `old_str`; se >1 e `replace_all=False`, **falha** com a contagem e sugestão de
   ampliar contexto. `old_str == new_str` ⇒ falha (no-op). Exige leitura prévia.
   Retorna trecho numerado ao redor da edição para confirmação visual.

4. **`multi_edit`** (nova tool): `path` + `edits: list[{old_str, new_str, replace_all?}]`.
   Aplica todas em sequência **em memória**; só grava no disco se todas passarem.
   Cada edição opera sobre o resultado da anterior (edições encadeadas). Se uma
   falhar, nada é escrito e o erro identifica qual edição e por quê.
   `requires={WRITE}`. Exige leitura prévia.

5. **`grep` com ripgrep**: detecta `rg` via `shutil.which`; usa `rg` por **lista de
   args** (nunca shell) quando disponível, senão fallback Python atual — **mesmo
   formato de saída** nos dois caminhos. Novos params: `output_mode`
   (`content`|`files_with_matches`|`count`), `context_lines` (`-C`), `glob_filter`,
   `case_insensitive`, `head_limit`. Truncamento sempre anunciado com contagem real.

6. **`todo_write`** (nova tool): `items: list[{content, status}]`, status em
   `pending`|`in_progress`|`completed`. Valida **no máximo um** `in_progress`.
   Emite `TodoEvent` (frozen, Pydantic) no `EventBus` a cada atualização. Registrado
   em `events/types.py`, exportado em `events/__init__.py` e adicionado ao
   `EVENT_CLASS_MAP` em `events/store.py`. `requires=frozenset()`, `read_only=False`.
   `create_filesystem_tools` ganha `event_bus: EventBus | None = None`; sem bus,
   valida e retorna sem emitir (degradação graciosa).

## Escopo explícito fora de M8
- `ToolResult` tipado, cancelamento, fold incremental, merge de deltas, contagem
  real de tokens → **M10**.
- API pública/CLI → **M9**. Checkpoints/LSP/classifier/worktree → **M11**.

## Definition of done
- Tools novas/alteradas registradas em `register_default_tools`.
- Testes offline: paginação/numeração, match ambíguo rejeitado, no-op rejeitado,
  rollback do `multi_edit`, fallback do grep sem `rg`, invariante de um único
  `in_progress`, round-trip do `TodoEvent` no `EventStore`.
- `make check` verde.
