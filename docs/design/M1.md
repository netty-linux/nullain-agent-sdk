# Design Document — Milestone M1: Camada LLM

## 1. Objetivo
Criar a porta de abstração `LLMProvider` (typing.Protocol) e a implementação `OllamaCloudProvider` com suporte a chat streaming, tool-calling nativo, contagem de tokens, retries exponenciais com jitter e mapeamento rigoroso de exceções de provedor.

## 2. Abstrações (`nullain/llm/types.py`)
- `Role`: `"system" | "user" | "assistant" | "tool"`
- `ToolCall`: `id`, `name`, `arguments` (dict)
- `FunctionSpec`: `name`, `description`, `parameters` (JSON Schema dict)
- `ToolSpec`: `type: "function"`, `function: FunctionSpec`
- `TokenUsage`: `prompt_tokens`, `completion_tokens`, `total_tokens`
- `ChatMessage`: Pydantic BaseModel com `role`, `content` (str | None), `tool_calls` (list[ToolCall] | None), `tool_call_id` (str | None), `name` (str | None).
- `CompletionRequest`: `model`, `messages`, `tools`, `temperature`, `max_tokens`, `stream`.
- `CompletionChunk`: `delta_text` (str), `tool_calls` (list[ToolCall] | None), `usage` (TokenUsage | None), `finish_reason` (str | None).

## 3. Interface `LLMProvider` (`nullain/llm/provider.py`)
`typing.Protocol` com os métodos:
- `async def generate(self, request: CompletionRequest) -> CompletionChunk`
- `async def stream(self, request: CompletionRequest) -> AsyncGenerator[CompletionChunk, None]`
- `async def health_check(self) -> bool`

## 4. `OllamaCloudProvider` (`nullain/llm/ollama.py`)
- Endpoint: Ollama API (`/api/chat`) e suporte OpenAI compat (`/v1/chat/completions`).
- Autenticação: Header `Authorization: Bearer <OLLAMA_API_KEY>` (ou token vindo da config).
- Resiliência: Retries com Tenacity para 429/5xx/Timeout com exponential backoff e jitter.
- Mapeamento de erros:
  - Timeout → `ProviderTimeoutError`
  - 429 → `ProviderRateLimitError`
  - 401/403 → `ProviderAuthenticationError`
  - 5xx / Outros → `ProviderError`

## 5. Critério de Aceite
- Suíte de testes unitários em `tests/unit/test_llm_provider.py` com `respx` cobrindo 100% dos cenários (sucesso, streaming, tool-calling, retry no 429, timeout e tratamento de 500).
- Exemplo executável `examples/00_llm_smoke.py`.
- `make check` 100% verde.
