# Design Document — Milestone M2: Eventos + Conversation

## 1. Objetivo
Implementar o modelo de Event Sourcing da conversa. O estado é uma sequência imutável de eventos Pydantic (`frozen=True`). O estado atual é derivado exclusivamente via função pura `fold`. Persistência local-first via SQLite async (`aiosqlite`) com suporte a replay completo.

## 2. Eventos (`nullain/events/types.py`)
Modelos Pydantic v2 com `frozen=True`:
- `BaseEvent`: `id`, `session_id`, `timestamp`, `type`
- `UserMessageEvent`: `content`
- `ModelResponseEvent`: `content`, `tool_calls`, `usage`, `model`
- `ToolCallEvent`: `call_id`, `tool_name`, `arguments`
- `ToolResultEvent`: `call_id`, `tool_name`, `output`, `is_error`
- `CompactionEvent`: `summary`, `trimmed_event_ids`
- `ErrorEvent`: `error_type`, `message`, `details`
- `SpecCreatedEvent`: `spec_id`, `title`, `steps`
- `SpecVerifiedEvent`: `spec_id`, `success`, `feedback`

## 3. Barramento de Eventos (`nullain/events/bus.py`)
- `EventBus`: Permite inscrição de handlers assíncronos (`subscribe(event_type, handler)`) e publicação de eventos (`publish(event)`).

## 4. Conversation & Event Fold (`nullain/events/conversation.py`)
- `ConversationState`: `session_id`, `events`, `messages`, `current_spec`, `total_tokens`.
- `Conversation.fold(events)`: Função pura que reconstrói a lista de mensagens para envio ao LLM e o estado agregador a partir dos eventos imutáveis.

## 5. Persistência SQLite (`nullain/events/store.py`)
- `EventStore`: Tabela `events` `(id TEXT PRIMARY KEY, session_id TEXT, timestamp REAL, event_type TEXT, payload JSON)`.
- Métodos async: `append(event)`, `get_session_events(session_id)`, `replay_session(session_id)`.

## 6. Critério de Aceite
- Property-based test com `hypothesis` em `tests/unit/test_events_property.py` provando que `serialize -> deserialize -> refold` preserva o estado idêntico.
- Testes unitários para `EventBus` e `EventStore`.
- `make check` 100% verde.
