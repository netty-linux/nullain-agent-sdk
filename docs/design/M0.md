# Design Document — Milestone M0: Fundação do Repo

## 1. Objetivo
Estabelecer a estrutura fundamental do monorepo `nullain-agent-sdk` com `uv` workspaces, tipagem estrita com Pyright, linting com Ruff, suíte de testes com Pytest, esteira de CI, tratamento de erros centralizado e telemetria inicial com structlog.

## 2. Estrutura de Diretórios
- `pyproject.toml` (Workspace root + pacotes `nullain-sdk`, `nullain-tools`, `nullain-agentd`)
- `Makefile` (comandos `check`, `test`, `lint`, `typecheck`, `schema`)
- `.gitignore` (bytecode, venv, `.env`, `.pytest_cache`, etc.)
- `.pre-commit-config.yaml` (ruff, ruff-format, gitleaks)
- `.github/workflows/ci.yml` (matriz Python 3.12/3.13, lint, typecheck, test, pip-audit)
- `nullain-sdk/`
  - `pyproject.toml`
  - `src/nullain/py.typed`
  - `src/nullain/__init__.py`
  - `src/nullain/errors.py`
  - `src/nullain/telemetry/__init__.py`
- `nullain-tools/`
  - `pyproject.toml`
  - `src/nullain_tools/py.typed`
  - `src/nullain_tools/__init__.py`
- `nullain-agentd/`
  - `pyproject.toml`
  - `src/nullain_agentd/py.typed`
  - `src/nullain_agentd/__init__.py`
- `tests/`
  - `conftest.py`
  - `unit/test_sentinel.py`
  - `integration/test_sentinel.py`

## 3. Hierarquia de Erros (`nullain/errors.py`)
- `NullainError` (Base)
  - `ProviderError` (Falhas na camada LLM)
    - `ProviderTimeoutError`
    - `ProviderRateLimitError`
    - `ProviderAuthenticationError`
  - `ToolError` (Falhas de execução/validação de ferramentas)
    - `ToolPermissionError`
    - `ToolExecutionError`
    - `ToolNotFoundError`
  - `RouterError` (Falhas no roteador de modelos)
    - `NoModelAvailableError`
  - `BudgetExceededError` (Orçamento de tokens/custo estourado)
  - `ContextError` (Erros de montagem de contexto ou estouro de janela)
  - `SpecValidationError` (Falha na especificação do agente)

## 4. Telemetria (`nullain/telemetry/__init__.py`)
- Setup de `structlog` com formatador JSON/Console.
- Helpers para injeção de contexto estruturado (session_id, step_id, model_name).

## 5. Ferramental & Qualidade
- Python version >= 3.12.
- Ruff com selecionadores `E,F,W,I,N,UP,B,S,A,C4,SIM,RUF`.
- Pyright em modo `strict`.
- Definition of Done: `make check` 100% aprovado.
