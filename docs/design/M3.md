# Design Document — Milestone M3: Tools, Sandbox & Permissões

## 1. Objetivo
Criar a infraestrutura de ferramentas do agente, incluindo o decorador `@tool` para extração automática de schemas JSON, o registro `ToolRegistry`, o motor de permissões `PermissionPolicy`, o isolamento em sandbox de sistema de arquivos e comandos, e as ferramentas built-in no pacote `nullain-tools`.

## 2. Decorador & Registry (`nullain/tools/`)
- `@tool`: Decorador Python que inspeciona a função, constrói o `ToolSpec` (JSON Schema dos parâmetros via Pydantic/inspect) e armazena docstrings.
- `ToolRegistry`: Gerencia o registro de ferramentas disponíveis, busca por nome e invocação validada.

## 3. Política de Permissões & Sandbox (`nullain/tools/permissions.py` & `nullain/tools/sandbox.py`)
- `PermissionLevel`: `ALLOW` (leitura), `ASK` (interativo/aprovação), `DENY` (proibido).
- `PermissionPolicy`: Avalia ações de tool. Padrões de negação nativos (`rm -rf`, `git push --force`, manipulação de `.env` ou chaves de API).
- File Sandbox: Valida todo caminho de arquivo via `Path.resolve()` e `is_relative_to(workspace_root)`. Resolve symlinks ANTES de verificar se estão contidos no workspace.
- Command Sandbox: Executa comandos SEMPRE via `asyncio.create_subprocess_exec` usando listas de argumentos. NUNCA utiliza `shell=True`. Aplica timeout e truncamento com ponteiro para o disco.

## 4. Built-in Tools (`nullain-tools/src/nullain_tools/`)
- `read_file(path: str)`: Lê arquivo do workspace.
- `write_file(path: str, content: str)`: Escreve arquivo no workspace.
- `edit_file(path: str, old_str: str, new_str: str)`: Substituição exata de string.
- `bash(command_args: list[str])`: Executa comando externo em lista de argumentos.
- `grep(pattern: str, path: str = ".")`: Busca textual no workspace.
- `git_status()`, `git_diff()`, `git_commit(message: str)`: Operações git controladas.

## 5. Critério de Aceite
- Suíte de segurança em `tests/unit/test_tools_security.py` cobrindo:
  - Tentativas de path traversal (`../../etc/passwd`).
  - Escape por symlink apontando para fora do workspace.
  - Injeção de shell (garantindo que argumentos sejam escapados/passados como lista).
  - Timeout de comando e truncamento de saída.
  - Property test com `hypothesis` para os validadores de caminho.
- `make check` 100% verde.
